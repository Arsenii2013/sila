## Система высокоскростной синхронизации комплекса СИЛА
Система состоит из двух видов устройств: мастеров-разветвителей (мастер-генератор событий, МГС, HSSM) и оконечных устройств (модуль оконечного устройства, МОУ, HSSR). Устройства соединяются оптическими линьками, сеть строится древовидно: в корне МГС в режиме мастера, в узлах - МГС в режиме разветвителя, а листья дерева - оконечные устройства МОУ. МОУ устанавливаются в устройства, требующие синхронизации: диагностики пучка, источники питания. Также для МОУ изготовлена плата носитель (локальный блок генерации сигналов, ЛБГС, HSSIO), которая позволяет генерировать электрические импульсы: 8 каналов с точной подстройкой задержки выдачи импульса (до 10 пс), и 8 каналов с грубой подстройкой (один такт, 5.714 нс). Точность синхронизации оконечных устройств составляет 20 пс.

МГС построены на SoC Xilinx Zynq 7100, МОУ на SoC Xilinx Zynq 7035. В ПЛИС реализована логика работы с оптикой, и логика работы устройства. В МГС - логика генерации событий (специальный пакет данных, который распространяется по сети синхронно), в МОУ - логика формирования по событиям синхроимпульсов. На процессоре собран и запущен дистрибутив Yocto Linux, запускающий управляющее ПО.

Система синхронизации разрабатывается, как развитие идей системы синхронизации [MRF](http://www.mrf.fi/index.php/timing-system)

Проект собирается системой сборки SCons, основные варианты сборки: `HSSM` - сгенерировать и собрать проект Vivado для МГС, `HSSR` - сгенерировать и собрать проект Vivado для МОУ, `top_test` - прогнать в  Questasim тест сети, конфигурация которой задается в `src/sim/topTB.sv`.
